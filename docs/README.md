# Documentation

Everything under `docs/`. This index is generated — run `bun run docs:sync`
after adding, renaming, or deleting a document. The table between the sync
markers is rewritten by the script; everything outside them is yours.

Linked from [`AGENTS.md`](../AGENTS.md). Start there for stack, hard rules, and
verification standards. This folder holds the detail behind those rules.

## Layout

| Path | Holds |
| :--- | :--- |
| `<topic-slug>/` | One folder per planning request: `plan.md`, `audit.md`, and `data/` when web material was captured. Generated by the planning rules. |
| [`archive/`](archive/) | Superseded documentation, kept for history. Never delete, move it here. |
| [`plans/`](plans/) | Legacy. Plans written before the topic-folder convention. Read-only — never write a new plan or audit here. |
| `.scratch/` | Temp and scratch files. Gitignored. Delete when done. |

Subfolder indexes (`archive/README.md`, and any topic or legacy folder that
keeps its own `README.md`) are generated by the same script and link back to
this page.

## Plan and audit location

When a plan and audit report are requested, they go in a **new topic folder**
created for that request: `docs/<topic-slug>/plan.md` and
`docs/<topic-slug>/audit.md`, with `docs/<topic-slug>/data/` created only when
something was pulled from the web. `<topic-slug>` is 2–4 lowercase kebab-case
words naming the topic, with no date prefix. The contract is defined in
[`.agents/rules/plan_and_documentation.md`](../.agents/rules/plan_and_documentation.md)
and repeated in the other two rules.

## Conventions

- Every document starts with a single `# ` H1, which becomes its title in the
  index above.
- Every document carries a `<!-- desc: one-line summary -->` comment on the line
  after the H1. The sync script fails loudly without it rather than guessing.
- Keep documents short and single-purpose. If one grows past a few hundred
  lines, split it and add an index.
- Link to `../AGENTS.md` and `../DESIGN.md` rather than restating their content.
- Update this index in the same turn as any change to a document's title,
  description, or location.
